## Проекты

### [ИИ-агент поиска работы](https://github.com/kiselev-ai/job-search-agent) — код открыт
Каждое утро собирает вакансии с hh.ru, отсеивает неподходящие, оценивает остальные через GigaChat с объяснением и присылает 5 лучших в Telegram с кнопками; по выбранным готовит черновик письма. Качество оценки калибровал по своим ручным оценкам: совпадение с моделью выросло с 12 до 18 вакансий из 20.
`Python` `GigaChat API` `Telegram Bot API` `JSON` `Git`

### Автоматизация разбора фотоосмотров линий электропередачи
Система распознаёт номера опор на фото, сверяет со справочником линий, раскладывает снимки по папкам и готовит Excel-отчёт с дефектами. Спецификация из 26 этапов, реализация на Python с Claude Code, проверка на реальных рабочих фото. Код не публикую — в нём рабочие данные.
`Python` `Claude Code` `распознавание изображений` `Excel`

### Telegram-бот для сети кофеен (демо)
Сделал по своей инициативе: заказ из меню, бронь, афиша, панель администратора, ИИ-консультант; меню на 280 позиций перенёс с фото в Google-таблицу.
`Telegram-бот` `Google Таблицы` `ИИ-консультант`

### Бренд-пакет и коммуникационная стратегия для кофейни
Итоговая работа курса: тексты, визуалы, карта пути клиента, воронка продаж — с помощью нейросетей.
