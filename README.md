## Проекты

### [ИИ-агент поиска работы](https://github.com/kiselev-ai/job-search-agent) — код открыт
Каждый день собирает вакансии с hh.ru, отсеивает неподходящие, оценивает остальные через GigaChat с объяснением и присылает 5 лучших в Telegram с кнопками; по выбранным готовит черновик письма. Качество оценки калибровал по своим ручным оценкам: совпадение с моделью выросло с 12 до 18 вакансий из 20.
`Python` `GigaChat API` `Telegram Bot API` `JSON` `Git`

### Автоматизация разбора фотоосмотров линий электропередачи
Система распознаёт номера опор на фото, сверяет со справочником линий, раскладывает снимки по папкам и готовит Excel-отчёт с дефектами. Спецификация из 26 этапов, реализация на Python с Claude Code, проверка на реальных рабочих фото. Код не публикую — в нём рабочие данные.
`Python` `Claude Code` `распознавание изображений` `Excel`

### [Telegram-бот для кофейни-библиотеки «Лампа Грина»](https://github.com/kiselev-ai/lampa-grina-bot) — демо, код открыт
Сделал по своей инициативе как предложение для кофейни: заказ к приходу, бронь столиков, афиша с записью, деловая библиотека, клубы и квиз, панель персонала, ИИ-консультант. Меню на 280 позиций перенёс с фото в таблицу; все сценарии проверяются автотестом без Telegram.
`Python` `aiogram 3` `SQLite` `Anthropic API`

### Бренд-пакет и коммуникационная стратегия для «Лампы Грина»
Итоговая работа курса: тексты, визуалы, карта пути клиента, воронка продаж — с помощью нейросетей.
